# 2026-09-13

Rev A's schematic was finished, assembly moved to the home workshop, all parts
were ordered, and the ERC rule set was tightened.

## Schematic complete — 14 nets

R1–R12 were drawn as six identical blocks in empty sheet space, joined to the
connectors by same-named labels. Netlist check: `ALL PASS`. References were
renumbered by hand: **R1–R6 are the series resistors, R7–R12 the pull-downs.**

Two faults were found and fixed:

- **A mislabelled net.** One block's driver-side label read `P1` instead of `B2`.
  On the board this would have shorted `INB2` to `PWM1` and left `B2`
  unconnected. **ERC reported nothing, before or after.** Found by eye during
  review.
- **Six dangling 50-mil wire stubs**, one in each block. Cause: Preferences →
  Schematic Editor → Grid Overrides pinned wires to 50 mils, half the 100-mil pin
  grid. Both overrides are now 100 mils. The six stubs were deleted by hand.

## Assembly moved to the home workshop

Soldering is done in the home workshop, not by the author. All soldering tools
are off the buy list, including the practice kit. **The multimeter stays, and is
now the only tool still to be bought.**

`fabrication.md` gained a four-item handover list: shortest parts first; both
boxed headers square to the board; whether R7–R12 are populated is decided before
the first joint; **no substitutions — 33 Ω and 10 kΩ are the specified values.**

Stage 0's exit criterion is now judging a solder joint rather than producing one.
The series resistors stay through-hole. JLCPCB assembly is not used.

## All parts ordered

Headers, both resistor types and both ribbon cables were bought. A 2026-09-11
entry recording the cables as "selected" was wrong — no order had been placed —
and is corrected in `tools-and-parts.md`. The enclosure is deferred until the
layout fixes the board outline.

## ERC tightened, then corrected

Two severities were raised: `footprint_filter` from `ignore` to **error**, and
`pin_to_pin` from warning to **error**.

**The count first recorded with this change, 30 / 0, was wrong.** Run against the
files, ERC reports **44 / 0**: the 30 by-design `pin_not_connected` errors plus 14
`footprint_filter`. An empty footprint field is compared like any other value and
matches no filter.

The 30 was the correct result for `footprint_filter: ignore`, read off KiCad's ERC
panel. **That panel does not re-run when a severity changes.** ERC is now run from
the command line; the commands are in `tools/README.md`.

# 2026-09-13 / 中文

Rev A 的原理图画完，焊接改在家里的工具间完成，物料全部下单，ERC 规则收紧。

## 原理图完工——14 个网络

R1–R12 画成六个一样的小块摆在空白处，靠同名标签接到连接器上。网表核对 `ALL PASS`。
编号全部手工改过：**R1–R6 是串阻，R7–R12 是下拉。**

发现并修掉两个错：

- **一个标签写错。** 有一块驱动侧的标签是 `P1` 而不是 `B2`。在板上这会让 `INB2` 与 `PWM1`
  短接，同时 `B2` 一个引脚都没接上。**ERC 全程一声不响。** 复查时用眼睛看出来的。
- **六段 50 mil 的悬空线头**，每块一段。原因：偏好设置 → 原理图编辑器 → 栅格重写把连线钉在
  50 mil，是 100 mil 引脚栅格的一半。两项重写现已改成 100 mil，六段线头手工删除。

## 焊接改在家里的工具间

焊接在家里的工具间完成，不由作者本人做。所有焊接工具从采购清单移除，练习板也一起。
**万用表保留，现在是唯一还要买的工具。**

`fabrication.md` 加了一张四条的交接清单：先焊矮的件；两个牛角座都要与板面垂直；R7–R12 焊不焊
在第一个焊点之前定下；**不许替换——33 Ω 和 10 kΩ 是指定值。**

第 0 阶段的判据改为"能判断一个焊点是否合格"，而不是"能做出一个焊点"。串阻保持通孔。
不使用嘉立创贴片服务。

**error**。
