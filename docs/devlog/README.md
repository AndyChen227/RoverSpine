# Devlog / 开发日志

One entry per working session that produced a result, bilingual, named
`YYYY-MM-DD-topic.md` — the same convention as
[RoverPi's devlog](https://github.com/AndyChen227/RoverPi/tree/main/docs/devlog).

**Sessions that failed get an entry too.** A board that did not work, written up
so the cause is clear, is the most valuable thing this repository can produce.

每次产出结果的工作都写一篇，中英双语，文件名 `YYYY-MM-DD-主题.md`，命名规则和
RoverPi 的开发日志一致。

**失败的那些同样要写。** 一块没做成的板子，只要把原因写清楚，就是这个仓库能产出的
最有价值的东西。
