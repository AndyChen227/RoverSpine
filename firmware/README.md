# Firmware / 固件

Code that runs on microcontrollers mounted on RoverSpine boards. Empty until
Stage 3, which is the first board with an MCU on it.

The Pi-side control code does not live here — it belongs to
[RoverPi](https://github.com/AndyChen227/RoverPi), by the boundary rule in the
[README](../README.md): facts about the rover live there, facts about the boards
live here.

运行在 RoverSpine 板载单片机上的代码。第 3 阶段之前为空——那是第一块带 MCU 的板。

Pi 端的控制代码不放在这里，它属于 [RoverPi](https://github.com/AndyChen227/RoverPi)。
按 [README](../README.md) 里的分工规矩：关于车的事实住在那边，关于板子的事实住在这边。
